# superwho-launch

Static pages served at launch.superwho.io (GitHub Pages, deploy from `main` / root).

- Each page lives in its own folder with an unguessable path; pages are shared by direct link only.
- The root page is intentionally blank, and every page sets `noindex`. `robots.txt` disallows all crawlers.
- Pages are single self-contained HTML files (fonts and images inlined).
